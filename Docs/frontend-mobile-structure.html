شرح مختصر لإطاري العمل

Angular (الويب)

إطار ويب من Google لبناء تطبيقات صفحة واحدة. كل شاشة غالباً ثلاثة ملفات: منطق TypeScript، قالب HTML، وتنسيق SCSS. التوجيه عبر المسارات، والبيانات من الـ API عبر خدمات HttpClient، مع حراس تمنع الدخول بدون تسجيل أو بدون صلاحية مسؤول.

Expo / React Native (الموبايل)

إطار لبناء تطبيق هاتف بـ React. الشاشة ملف tsx واحد يجمع الواجهة والمنطق. Expo يشغّله على Android وiOS والمتصفح. نفس الـ API، والتنقل عبر React Navigation (تبويبات سفلية ومكدس شاشات).

كلا التطبيقين عربيان (RTL) ويتصلان بـ ASP.NET Core. التسلسل: مساحة عمل ← مشروع ← مهمة. الأدوار: مالك، مدير مشروع، عضو، ومسؤول نظام.
